# Реорганизация проекта: задачи и решения

Проект остаётся статическим сайтом без сборщика. Страницы сгруппированы по типам проектов, а локальные ресурсы лежат рядом с проектом. Общие ресурсы находятся в `assets/`.

## Согласованные решения

- `shifting-tiles` относится к галереям: это способ переключения изображений.
- В экспериментах оставлена папка `t-free-techno/`; отдельной папки `music/` нет.
- Встроенные скрипты корневого `index.html` остаются в самом файле.
- Имена файлов и папок должны быть понятны человеку.
- Старые HTML-переходники удалены, навигация указывает на актуальные страницы.
- Изображения `shifting-tiles` и `web-gallery` объединены в `assets/images/gallery/`.

## Запуск локально

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000/>. Локальный HTTP-сервер нужен страницам, которые загружают JSON через `fetch`.
